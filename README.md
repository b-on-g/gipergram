# Gipergram

Неофициальный веб-клиент Telegram на $mol. Транспорт — GramJS (MTProto), грузится с esm.sh при входе.

- Вкладки открытых чатов: чат, который открыл, остаётся наверху списка, пока сам не закроешь. Кнопка ↑ поднимает вкладку выше остальных, посты каналов порядок не сбивают.
- Несколько чатов рядом: отметь «держать рядом», и на широком экране чаты встанут колонками.
- Своя отметка непрочитанного: открытие чата и случайная прокрутка её не двигают. Двигает кнопка «прочитано» или отправка сообщения, и последнее движение можно отменить.
- Мои сообщения: лента всего, что ты написал, со ссылками в чаты.

## Ключи

Зарегистрируй приложение на https://my.telegram.org → API development tools и впиши `api_id` и `api_hash` в `tg/tg.ts`.

## Разработка

```
npm start
open http://localhost:9080/bog/gipergram/app/-/test.html
```
